# How to run it
Run containers
```
make dev
```
Run docker on background
```
make dev-d
```
Remove containers
```
make down
```
# Formatting and linting:
```
npx eslint
```
```
npx prettier --check app/src
npx prettier --write app/src

```
# Running tests:
```
npx vitest run
```
